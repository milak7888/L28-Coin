# Foundation 135 — Public Community Validation Entrypoint v0.1

**Status:** documentation integration / non-activating

Foundation 135 exposes the existing offline UAII community conformance runner
and deterministic report from the repository README and adds contributor
guidance.

This milestone changes no Protocol, UAII schema, adapter, SDK, fixture,
validation implementation, economic record, runtime, network, wallet,
signer, broadcast, mining, bridge, deployment, testnet, or settlement path.

Public conformance results remain evidence only and are not production
security certification or independent human security review.

Protocol v1.0.0 remains frozen.
