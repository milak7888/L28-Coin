# Local Signer Atomic State Decision Proposals v0.1

Status: `PROPOSALS_ONLY_NON_APPROVING`

Foundation: 126, workstream 3

Coverage: `LSOD-STA-001` through `LSOD-STA-012`

## 1. Review boundary

This document compares unapproved candidate shapes for future local security state. It creates no database, schema, migration, transaction engine, store, runtime, service, signer, wallet, key, network, RPC, broadcast, or settlement behavior. Every decision remains `CANDIDATE_NOT_APPROVED`.

Local replay/spending/approval state is not the L28 ledger or consensus. `coin.tx_validation.validate_transaction` remains canonical and mandatory. Authorization is not validation; committed eligibility is not signer invocation. Missing, corrupt, stale, ambiguous, or unavailable authoritative state fails closed.
